BUG #2 Race condition in idempotency check CRITICAL

หลาย engines ตรวจ idempotency_key แล้ว set → 2 requests พร้อมกัน (parallel) ทำให้ double execution (double credit, double redeem, etc.)

// Before (BAD) if (!idempotencyKey) { /* check + set */ }
// After (GOOD) - per-key lock + serialization await idemLock.withLock(idempotency_key, async () => { if (exists) return existing; const result = await performOp(); save(result); return result; });
  • ✅ IdempotencyLock class (mutex pattern)
  • ✅ Serializes same-key operations (parallel = race)
  • ✅ Allows parallel different keys (no false serialization)
