🏆 Reward Engine (PF-3)

Fixes A6 A7 A12   Cron job เคย fail เงียบๆ → ตอนนี้ retry + audit + idempotent

4 Reward Types

TypeTriggerUse Case
DAILY_CLAIMCron (nightly)Lock&Earn, daily check-in
REFERRAL_BONUSUser inviteInvite friend
EVENT_BONUSCampaignLock-to-win, promo
MIGRATION_BONUSPF-1AAM → LP2.0 incentive

Grant Flow

1. Check claim_id (idempotency)
2. Validate wallet + amount
3. Loop 3 retries w/ backoff
4. ledger.credit() (source of truth)
5. wallets.incrementBalance() (cache)
6. markClaim(GRANTED)
7. audit + notify user

Failure → markClaim(FAILED) → DLQ

🔄 Replay Failed Claims (Admin Tool)

Sample Code

// Subscribe
bus.subscribe('phone.changed', async (e) => {
  await walletAPI.updatePhone(e.payload);
});

// Publish (from MS24)

  person_id: 'P1234',
  old_phone_hash: 'OLD',
  new_phone_hash: 'NEW',
  source: 'ms24'
});
