🔄 A14: AAMpoint ไม่เข้ากระเป๋า

Bug Fix Cross-tenant  สมาชิก AAMpoint หลายคนไม่มี AAMpoint ขึ้น

Bug #A14 · Status: ✅ Reconcile ready

Root cause: AAM tenant ledger มี point แต่ cross-tenant sync ยังไม่ propagate มา LP2.0 wallet (PF-4 SQS จะ fix ที่ write-time, ตัวนี้ fix ที่ read-time)

Fix: getAAMPoint() pull จาก AAM ledger (source of truth) → heal wallet cache → return fresh balance
