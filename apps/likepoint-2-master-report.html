📝 What (อะไรเกิดขึ้น)

ผู้ใช้งานพบว่า ข้อมูล Asset แสดงผลไม่เหมือนกันในแต่ละครั้ง ทั้งๆ ที่ยังไม่มีอะไรเปลี่ยนแปลง — Dev ตรวจพบ:

  • แหล่งที่เก็บ Asset (Wallet) มีหลายที่ — wallet ถูกสร้างซ้ำซ้อนหลาย record
  • UI ดึง asset จาก wallet record ต่างกันในแต่ละ request → ได้ค่าต่างกัน

🎯 Root Cause (2 ปัญหาหลัก)

1. Prod ไม่มีกระบวนการตรวจการสร้าง wallet

2. กระบวนการสร้าง wallet สามารถสร้างได้หลายครั้งไม่มีการ Fix

PriorityHypothesisProbability

2H3: Race Condition (2 requests พร้อมกัน)สูง

2️⃣ แผนนำเสนอเพื่อแก้ไขอย่างไร

🚨 Hotfix (ภายใน 1-3 วัน)

  1. App-level check: เช็ค wallet มีอยู่แล้วก่อนสร้าง (4 ชม.)
  2. Idempotency-Key Header: client + server (1 วัน)
  3. Data cleanup: merge duplicates + soft delete (2 ชม.)

🔧 Proper Fix (ภายใน 1-2 สัปดาห์)

  2. SELECT FOR UPDATE: race condition lock (1 วัน)
  3. Redis Idempotency: cache result 24h (2 วัน)

H3: Race Condition (SELECT FOR UPDATE)

BEGIN;
  SELECT * FROM wallets 
  WHERE user_id=$1 AND wallet_type=$2 
  FOR UPDATE;  -- lock row
  -- ถ้าเจอ → return
  -- ถ้าไม่เจอ → INSERT (unique constraint กันซ้ำได้แล้ว)
COMMIT;

🔍 Investigation Steps

  1. SELECT * FROM information_schema.table_constraints WHERE table_name='wallets';
  2. SELECT user_id, wallet_type, COUNT(*) FROM wallets GROUP BY 1,2 HAVING COUNT(*) > 1;
  3. ดู audit log + network log (concurrent / retry pattern)
  4. Code search "INSERT INTO wallets" / "createWallet" — มี unique check ไหม
